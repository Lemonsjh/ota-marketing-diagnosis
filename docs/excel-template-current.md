# S14 Excel 填报模板

服务器下载模板由 `marketing_diagnosis/excel_template.py` 生成。
现有中文工作表名称保持不变，系统模块和各区域表头不要修改。
示例行默认不导入，使用真实数据覆盖后将“是否导入”设为“是”。
黄色新增行已预填系统模块；复制新增行时要复制整行。

## 当前口径

- 美团推广：填写同一近30天周期的推广投入、推广预订订单金额，系统计算 ROI。不用月度 PMS 渠道房费收入替代。
- 携程推广：填写平台近30天推广投入、订单、订单金额、曝光、点击及平台 ROI。
- 昨日新增点评：填写实际点评统计日期和该日新增数量。没有取得数量时留空，不能填零代替未知。
- 视频：美团和携程分别填写已上传数量及需上传数量。
- 携程专属区域：流量漏斗、PSI、用户画像、竞争圈、点评、权益、配置状态、售卖房型、视频与活动数据。
- 仅填写本酒店实际经营的平台，没有的平台保持“否”。
- 全部导入区域的酒店ID必须相同，并与当前机器人绑定酒店一致。

## 数值与周期

原有比例字段沿用模板说明，填写小数或Excel百分比。
新增标注 `(%)` 的字段填写0–100数值，例如10表示10%；也支持Excel百分比单元格或文字 `10%`。
排名填写名次，同行酒店总数单独填写，不能用本店名次代替酒店总数。
推广、同行比较和画像必须使用各自明确的同一统计起止日期。
未知值保持空白，确定为零时才填写0。

## 兼容与校验

旧版多区域中文文件、旧版独立工作表文件继续支持读取。
完整旧模板允许根据区域标题识别空白的系统模块列；没有模块列值且没有完整区域标题的片段不再静默跳过。
旧版推广交易和月度渠道收入字段仍可解析，但不再推荐填写，不能代替当前推广 ROI 的输入。
选择“是”却缺少酒店ID或关键推广输入的行会报错并指出位置。
填报总览只统计选择导入的行数，不表示所有字段已通过校验。
